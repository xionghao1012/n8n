# HTTP请求节点 | n8n-io/n8n | DeepWiki  
本文档详解n8n中HTTP请求节点的实现架构，该节点提供与外部API和服务通信的核心功能，是n8n生态中最基础的关键节点。

## 架构概览  
HTTP请求节点采用版本化设计，支持功能演进的同时保持向后兼容。系统提供多种认证方式、请求格式及高级功能（如分页和二进制数据处理）。

## 核心实现  
### 主节点类结构  
`HttpRequest`类继承`VersionedNodeType`并管理多版本实现。  
每个版本类通过`INodeType`接口实现：  
- `description`：完整的节点参数定义  
- `execute()`：处理HTTP请求的核心执行逻辑

## 认证系统  
HTTP请求节点支持跨版本的全面认证机制。  

### 各版本认证类型对比  
| 认证方式         | V1  | V2  | V3/V4 | 实现凭证类型              |  
|------------------|-----|-----|-------|--------------------------|  
| 无认证           | ✅  | ✅  | ✅    | -                        |  
| 基础认证         | ✅  | ✅  | ✅    | `httpBasicAuth`          |  
| Bearer令牌       | ❌  | ✅  | ✅    | `httpBearerAuth`         |  
| Digest认证       | ✅  | ✅  | ✅    | `httpDigestAuth`         |  
| Header认证       | ✅  | ✅  | ✅    | `httpHeaderAuth`         |  
| Query认证        | ✅  | ✅  | ✅    | `httpQueryAuth`          |  
| OAuth 1.0        | ✅  | ✅  | ✅    | `oAuth1Api`              |  
| OAuth 2.0        | ✅  | ✅  | ✅    | `oAuth2Api`              |  
| 自定义认证       | ❌  | ❌  | ✅    | `httpCustomAuth`         |  
| SSL证书          | ❌  | ❌  | ✅    | `httpSslAuth`            |  
| 预定义服务       | ❌  | ✅  | ✅    | 服务特定凭证             |
