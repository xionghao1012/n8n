# HTTP Request Node | n8n-io/n8n | DeepWiki

This document covers the implementation and architecture of the HTTP Request node in n8n, which provides the core functionality for making HTTP requests to external APIs and services. The HTTP Request node is one of the most fundamental nodes in the n8n ecosystem, enabling workflows to interact with virtually any web service.

## Architecture Overview

The HTTP Request node is implemented as a versioned node type, allowing for evolution while maintaining backward compatibility. The system supports multiple authentication methods, request formats, and advanced features like pagination and binary data handling.

## Core Implementation

### Main Node Class Structure

The `HttpRequest` class extends `VersionedNodeType` and manages multiple implementations.

Each version class implements the `INodeType` interface with:
- `description`: Complete node parameter definitions
- `execute()`: Main execution logic for processing HTTP requests
