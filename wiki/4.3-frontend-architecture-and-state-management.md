# Frontend Architecture and State Management | n8n-io/n8n | DeepWiki

This document covers the frontend architecture of the n8n workflow automation platform, focusing on the Vue.js application structure, Pinia-based state management, and component organization. The frontend is a single-page application (SPA) that provides the visual workflow editor, user authentication, settings management, and integration with the n8n backend API.

For information about the workflow execution engine and backend services, see [Workflow Execution Engine](https://deepwiki.com/n8n-io/n8n/2-workflow-execution-engine). For details about the node system and integrations, see [Node System](https://deepwiki.com/n8n-io/n8n/3-node-system).

## Architecture Overview

The n8n frontend follows a modular Vue.js architecture with centralized state management using Pinia stores, TypeScript for type safety, and a component-based UI structure.

## Pinia Store Architecture

The application uses Pinia for state management with dedicated stores for different concerns. Each store follows the Composition API pattern and provides reactive state, computed properties, and actions.
