Main CLI Commands
-----------------

### Start Command (`n8n start`)

The primary command that launches a full n8n instance with web UI, API server, and workflow execution capabilities.

| Flag | Description | Example |
| --- | --- | --- |
| `--tunnel` | Runs webhooks via hooks.n8n.cloud tunnel | `n8n start --tunnel` |
| `--open` | Automatically opens UI in browser | `n8n start -o` |
| `--reinstallMissingPackages` | Attempts to reinstall missing community packages | `n8n start --reinstallMissingPackages` |

The start command initializes multiple subsystems including the ActiveWorkflowManager, Server, and various scaling components based on the execution mode configuration.

**Sources:**[packages/cli/src/commands/start.ts 40-409](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/commands/start.ts#L40-L409)

### Worker Command (`n8n worker`)

Launches a worker process for distributed execution in queue mode.

| Flag | Description | Default |
| --- | --- | --- |
| `--concurrency` | Number of jobs that can run in parallel | 10 |

The worker command requires `EXECUTIONS_MODE=queue` and sets up job processing capabilities through the ScalingService.

**Sources:**[packages/cli/src/commands/worker.ts 18-192](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/commands/worker.ts#L18-L192)

### Webhook Command (`n8n webhook`)

Starts a dedicated webhook server for handling external triggers in distributed setups.

This command only intercepts production webhook URLs and requires queue mode to be enabled. It's designed for scenarios where webhook processing needs to be separated from the main n8n instance.

**Sources:**[packages/cli/src/commands/webhook.ts 13-104](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/commands/webhook.ts#L13-L104)

### Execute Commands

Two execution commands are available for CLI-based workflow execution:

*   `execute` - Executes a single workflow by ID
*   `execute-batch` - Executes multiple workflows with advanced options like retries and comparison modes

**Sources:**[packages/cli/src/commands/execute.ts](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/commands/execute.ts)[packages/cli/src/commands/execute-batch.ts](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/commands/execute-batch.ts)

### Configuration Loading

The system supports loading sensitive values from files using `_FILE` suffix:

`// Example: DB_POSTGRESDB_PASSWORD_FILE=/secrets/db_password`
This pattern allows secure handling of credentials in containerized environments.
