This document presents additional service integration examples beyond the HTTP Request Node (see [HTTP Request Node](https://deepwiki.com/n8n-io/n8n/3.1-http-request-node)) and standard service integration patterns (see [Service Integration Nodes](https://deepwiki.com/n8n-io/n8n/3.2-service-integration-nodes)). The examples covered here demonstrate diverse integration approaches including WebDAV protocols, token-based authentication, and URL manipulation services.

These examples illustrate how n8n handles different API architectures and authentication mechanisms across cloud storage platforms, database systems, and web services.

### NextCloud Operations Matrix

| Resource | Operations | HTTP Methods | API Type |
| --- | --- | --- | --- |
| File | upload, download, copy, move, delete, share | PUT, GET, COPY, MOVE, DELETE, POST | WebDAV + OCS |
| Folder | create, list, copy, move, delete, share | MKCOL, PROPFIND, COPY, MOVE, DELETE, POST | WebDAV + OCS |
| User | create, get, getAll, update, delete | POST, GET, PUT, DELETE | OCS |

### Credential Type Patterns

The four integrations showcase different credential approaches:

| Integration | Credential Types | Authentication Method | Special Features |
| --- | --- | --- | --- |
| NextCloud | `nextCloudApi`, `nextCloudOAuth2Api` | Basic Auth, OAuth2 | Dual auth support, WebDAV URL |
| FileMaker | `fileMaker` | Username/Password → Token | Session management |
| Yourls | `yourlsApi` | Signature-based | Simple API key |
| Git | `gitPassword` | Username/Password → URL injection | Optional auth, CLI integration |

Sources: [packages/nodes-base/credentials/NextCloudApi.credentials.ts 9-57](https://github.com/xionghao1012/n8n/blob/master/packages/nodes-base/credentials/NextCloudApi.credentials.ts#L9-L57)[packages/nodes-base/credentials/FileMaker.credentials.ts 3-39](https://github.com/xionghao1012/n8n/blob/master/packages/nodes-base/credentials/FileMaker.credentials.ts#L3-L39)[packages/nodes-base/credentials/YourlsApi.credentials.ts 3-25](https://github.com/xionghao1012/n8n/blob/master/packages/nodes-base/credentials/YourlsApi.credentials.ts#L3-L25)
