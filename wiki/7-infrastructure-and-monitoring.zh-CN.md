Prometheus指标系统
-------------------------

n8n通过兼容Prometheus的指标端点提供全面监控，该端点公开系统性能数据、应用程序指标和操作洞察。

### PrometheusMetricsService架构

`PrometheusMetricsService`类作为指标收集和暴露的核心组件：

**Prometheus指标系统架构**

来源：[packages/cli/src/metrics/prometheus-metrics.service.ts 21-347](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/metrics/prometheus-metrics.service.ts#L21-L347)

### 指标类别和配置

指标系统支持五大类别，每种类别都可通过环境变量配置：

| 类别 | 环境变量 | 描述 |
| --- | --- | --- |
| `default` | `N8N_METRICS_INCLUDE_DEFAULT_METRICS` | Node.js进程指标（CPU、内存、事件循环） |
| `routes` | `N8N_METRICS_INCLUDE_API_ENDPOINTS` | HTTP请求持续时间和活动 |
| `cache` | `N8N_METRICS_INCLUDE_CACHE_METRICS` | 缓存命中、未命中和更新 |
| `logs` | `N8N_METRICS_INCLUDE_MESSAGE_EVENT_BUS_METRICS` | 内部事件计数器 |
| `queue` | `N8N_METRICS_INCLUDE_QUEUE_METRICS` | 作业队列统计信息（仅缩放模式） |

### 公开的关键指标

#### 系统指标

| 指标名称 | 类型 | 描述 |
|-------------|------|-------------|
| `process_cpu_user_seconds_total` | 计数器 | 用户CPU总时间（秒） |
| `process_cpu_system_seconds_total` | 计数器 | 系统CPU总时间（秒） |
| `process_cpu_seconds_total` | 计数器 | 用户和系统CPU总时间 |
| `process_resident_memory_bytes` |  gauge | 常驻内存大小（字节） |
| `process_heap_bytes` |  gauge | 进程堆大小（字节） |
| `nodejs_eventloop_lag_seconds` |  gauge | 事件循环延迟（秒） |
| `nodejs_active_handles` |  gauge | 活动句柄数量 |
| `nodejs_active_requests` |  gauge | 活动请求数量 |

#### 应用程序指标

| 指标名称 | 类型 | 描述 |
|-------------|------|-------------|
| `n8n_workflow_executions_total` | 计数器 | 工作流执行总数 |
| `n8n_workflow_execution_seconds` | 直方图 | 工作流执行持续时间（秒） |
| `n8n_node_executions_total` | 计数器 | 节点执行总数 |
| `n8n_node_execution_seconds` | 直方图 | 节点执行持续时间（秒） |
| `n8n_credentials_usage_total` | 计数器 | 凭证使用总数 |
| `n8n_api_requests_total` | 计数器 | API请求总数 |
| `n8n_api_request_duration_seconds` | 直方图 | API请求持续时间（秒） |

#### 缓存指标

| 指标名称 | 类型 | 描述 |
|-------------|------|-------------|
| `n8n_cache_hits_total` | 计数器 | 缓存命中总数 |
| `n8n_cache_misses_total` | 计数器 | 缓存未命中总数 |
| `n8n_cache_updates_total` | 计数器 | 缓存更新总数 |
| `n8n_cache_size_bytes` |  gauge | 当前缓存大小（字节） |

#### 队列指标（仅缩放模式）

| 指标名称 | 类型 | 描述 |
|-------------|------|-------------|
| `n8n_queue_jobs_total` | 计数器 | 处理的作业总数 |
| `n8n_queue_job_duration_seconds` | 直方图 | 作业处理持续时间（秒） |
| `n8n_queue_active_workers` |  gauge | 活动工作器数量 |
| `n8n_queue_waiting_jobs` |  gauge | 队列中等待的作业数量 |

配置管理基础设施
--------------------------------------

配置系统遵循分层结构：

1. **GlobalConfig**：从环境变量加载的基本配置
2. **DatabaseConfig**：数据库特定设置
3. **SecurityConfig**：安全相关设置
4. **EndpointsConfig**：API端点配置
5. **WorkflowsConfig**：工作流执行设置
6. **UserManagementConfig**：用户管理设置
7. **TemplatesConfig**：模板管理设置
8. **PublicApiConfig**：公共API设置
9. **EventBusConfig**：事件总线设置
10. **CacheConfig**：缓存设置
11. **CredentialsConfig**：凭证管理设置
12. **InsightsConfig**：洞察和分析设置

事件总线和内部监控
---------------------------------

事件总线提供内部系统事件的实时监控：

| 事件类型 | 描述 |
|-----------|-------------|
| `workflow.started` | 工作流执行开始 |
| `workflow.completed` | 工作流执行完成 |
| `workflow.failed` | 工作流执行失败 |
| `node.started` | 节点执行开始 |
| `node.completed` | 节点执行完成 |
| `node.failed` | 节点执行失败 |
| `credentials.used` | 凭证已使用 |
| `credentials.updated` | 凭证已更新 |
| `credentials.deleted` | 凭证已删除 |
| `user.loggedIn` | 用户已登录 |
| `user.loggedOut` | 用户已登出 |
| `user.created` | 用户已创建 |
| `user.updated` | 用户已更新 |
| `user.deleted` | 用户已删除 |
