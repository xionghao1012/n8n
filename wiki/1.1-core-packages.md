For frontend architecture details, see [User Interface](https://deepwiki.com/n8n-io/n8n/4-user-interface).

Monorepo Structure
------------------

n8n uses a pnpm workspace-based monorepo containing multiple interconnected packages. The core packages provide the essential functionality for workflow execution, node management, CLI interface, and web UI.

Package Responsibilities
------------------------

### CLI Package (`n8n`)

The main entry point package that provides the command-line interface and Express server. It orchestrates all other components and handles process lifecycle management.

| Component | Description | Key Code Entities |
| --- | --- | --- |
| `bin/n8n` | Main executable binary | Oclif command dispatcher |
| `dist/commands/` | CLI command implementations | `start`, `worker`, `webhook` commands |
| Express Server | REST API and UI serving | `express@5.1.0`, middleware stack |
| Workflow Runner | Execution orchestration | `WorkflowRunner`, `ScalingService` |
| Authentication | User management | `passport`, `jsonwebtoken@9.0.2` |
| Database | Data persistence | `@n8n/typeorm@0.3.20-12`, migrations |

### Core Package (`n8n-core`)

Contains the core execution engine, node type loading, and workflow processing logic.

| Component | Description | Key Code Entities |
| --- | --- | --- |
| Workflow Execution | Core execution logic | `WorkflowExecute` class |
| Node Loading | Dynamic node registration | `NodeTypes`, `LoadNodesAndCredentials` |
| Binary Data | File handling utilities | `BinaryDataService`, file streaming |
| Helper Functions | Node execution helpers | `NodeExecuteFunctions`, `this.helpers` |
| SSH Tunneling | Secure connections | `ssh2@1.15.0`, tunnel management |
| HTTP Requests | External API calls | `axios@1.8.3` with proxy support |

### Workflow Package (`n8n-workflow`)

Provides foundational workflow definitions, node interfaces, and expression evaluation.

| Component | Description | Key Code Entities |
| --- | --- | --- |
| `INode` interfaces | Node type definitions | `INodeType`, `INodeTypeDescription` |
| `Workflow` class | Workflow orchestration | Graph execution, node resolution |
| Expression resolver | `${}` syntax evaluation | `ExpressionEvaluatorProxy`, JSMath |
| Validation schemas | Zod-based validation | Input validation, type checking |
| Utility functions | Data transformation | `jmespath@0.16.0`, data mapping |

### Nodes Base Package (`n8n-nodes-base`)

Contains 400+ built-in integration nodes and their credential definitions.

| Component | Description | Key Code Entities |
| --- | --- | --- |
| Node Implementations | Service integrations | `.node.js` files, operation handlers |
| Credential Definitions | Authentication configs | `.credentials.js` files |
| Node Metadata | Registration info | `package.json` n8n section arrays |
| Utility Scripts | Build helpers | `copy-nodes-json.js`, metadata generation |

Build System Architecture
-------------------------

The monorepo uses TurboRepo for coordinated builds across packages with TypeScript compilation and asset processing. Each package has specialized build steps for its content type.

**Build Pipeline Flow**

**Build Scripts by Package**

| Package | Build Command | Key Steps | Output Structure |
| --- | --- | --- | --- |
| `n8n` | `tsc -p tsconfig.build.json && tsc-alias -p tsconfig.build.json && node scripts/build.mjs` | Compile CLI, resolve paths, custom build | `dist/`, `bin/n8n` |
| `n8n-core` | `tsc -p tsconfig.build.json && tsc-alias -p tsconfig.build.json` | Compile core engine | `dist/`, `bin/` utilities |
| `n8n-workflow` | `tsc -p tsconfig.build.json` | Compile workflow definitions | `dist/index.js`, type declarations |
| `n8n-nodes-base` | `tsup --tsconfig tsconfig.build.json && pnpm copy-nodes-json && tsc-alias -p tsconfig.build.json && pnpm n8n-copy-static-files && pnpm n8n-generate-translations && pnpm n8n-generate-metadata` | Bundle nodes, copy assets, generate metadata | `dist/nodes/`, `dist/credentials/` |
| `@n8n/nodes-langchain` | `tsup --tsconfig tsconfig.build.json && pnpm copy-nodes-json && tsc-alias -p tsconfig.build.json && cp utils/tokenizer/*.json dist/utils/tokenizer/ && pnpm n8n-copy-static-files && pnpm n8n-generate-metadata` | Bundle AI nodes, copy tokenizers | `dist/nodes/`, AI-specific assets |

**Development Mode Commands**

| Package | Dev Command | Watch Strategy |
| --- | --- | --- |
| `n8n` | `concurrently -k -n \"TypeScript,Node\" -c \"yellow.bold,cyan.bold\" \"npm run watch\" \"nodemon\"` | TypeScript watch + nodemon restart |
| `n8n-core` | `tsc-watch -p tsconfig.build.json --onCompilationComplete \"tsc-alias -p tsconfig.build.json\"` | TypeScript watch with alias resolution |
| `n8n-nodes-base` | `tsup --watch --tsconfig tsconfig.build.json --onSuccess \"pnpm copy-nodes-json && tsc-alias -p tsconfig.build.json && pnpm n8n-generate-metadata\"` | Watch with metadata regeneration |

Workspace Configuration
-----------------------

The pnpm workspace is configured to include multiple package directories with catalog-based dependency management for consistent versioning.

### Catalog Dependencies

Key shared dependencies managed through the catalog system:

| Category | Dependencies | Version |
| --- | --- | --- |

| Validation | `zod`, `zod-to-json-schema` | `3.24.1`, `3.23.3` |
| AI/ML | `@langchain/core`, `@langchain/openai` | `0.3.48`, `0.5.0` |
