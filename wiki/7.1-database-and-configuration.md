Database Configuration System
-----------------------------

n8n supports multiple database backends through a unified configuration system. The `DatabaseConfig` class provides type-safe configuration for SQLite, PostgreSQL, MySQL, and MariaDB databases.

### Supported Database Types

The system supports four database types defined in [packages/@n8n/config/src/configs/database.config.ts 143-144](https://github.com/xionghao1012/n8n/blob/master/packages/@n8n/config/src/configs/database.config.ts#L143-L144):

| Database Type | Configuration Class | Default Settings |
| --- | --- | --- |
| `sqlite` | `SqliteConfig` | `database.sqlite`, pooling disabled |
| `postgresdb` | `PostgresConfig` | `localhost:5432`, user `postgres` |
| `mysqldb` | `MysqlConfig` | `localhost:3306`, user `root` |
| `mariadb` | `MysqlConfig` | Same as MySQL |

### SQLite Configuration Options

SQLite supports both traditional and pooled connection modes:

| Setting | Environment Variable | Default | Description |
| --- | --- | --- | --- |
| `database` | `DB_SQLITE_DATABASE` | `database.sqlite` | Database file name |
| `poolSize` | `DB_SQLITE_POOL_SIZE` | `0` | Connection pool size (0 = disabled) |
| `enableWAL` | `DB_SQLITE_ENABLE_WAL` | `true` if pooled | Write-Ahead Logging mode |
| `executeVacuumOnStartup` | `DB_SQLITE_VACUUM_ON_STARTUP` | `false` | Run VACUUM on startup |

Migration and Schema Management
-------------------------------

Database migrations are handled through TypeORM's migration system with n8n-specific wrappers for enhanced error handling and logging.

### Migration Execution Flow

**Sources:**[packages/cli/src/databases/db-connection.ts 68-73](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/databases/db-connection.ts#L68-L73)[packages/cli/src/databases/db-connection-options.ts 6-8](https://github.com/xionghao1012/n8n/blob/master/packages/cli/src/databases/db-connection-options.ts#L6-L8)
