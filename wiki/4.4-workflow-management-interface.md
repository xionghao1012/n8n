# Workflow Management Interface | n8n-io/n8n | DeepWiki

This document covers the workflow management interface components in n8n's frontend, focusing on the workflow list view, execution interface, and workflow operation controls. This interface allows users to browse, execute, monitor, and manage their workflows through a web-based UI.

For information about the workflow canvas and node editing interface, see [Node Details View (NDV)](https://deepwiki.com/n8n-io/n8n/4.1-node-details-view-(ndv)). For details about frontend architecture and state management, see [Frontend Architecture and State Management](https://deepwiki.com/n8n-io/n8n/4.3-frontend-architecture-and-state-management).

## Overview

The workflow management interface consists of two primary views: the workflow list view for browsing and organizing workflows, and the execution interface for running and monitoring workflow execution. These interfaces are built using Vue.js components and integrate with the REST API for workflow operations.
