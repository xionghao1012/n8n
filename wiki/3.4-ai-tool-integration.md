# AI Tool Integration | n8n-io/n8n | DeepWiki

This document covers the LangChain integration and AI-specific nodes available in n8n for building AI agent workflows. The `@n8n/nodes-langchain` package provides a comprehensive set of nodes for language models, vector stores, document processing, and AI agents.

For information about the broader node system architecture, see [Node System](https://deepwiki.com/n8n-io/n8n/3-node-system). For details on service integration nodes, see [Service Integration Nodes](https://deepwiki.com/n8n-io/n8n/3.2-service-integration-nodes).

## Package Architecture

The AI tool integration is implemented as a separate package `@n8n/nodes-langchain` within the n8n monorepo, providing modular AI capabilities that can be independently developed and versioned.

## Document Processing Pipeline

The AI integration includes comprehensive document processing capabilities for RAG workflows:

| Component Type | Node Examples | Purpose |
| --- | --- | --- |
| **Document Loaders** | `DocumentDefaultDataLoader.node.js`, `DocumentBinaryInputLoader.node.js`, `DocumentGithubLoader.node.js` | Load documents from various sources |
| **Text Splitters** | `TextSplitterRecursiveCharacterTextSplitter.node.js`, `TextSplitterTokenSplitter.node.js` | Split documents into manageable chunks |
| **Output Parsers** | `OutputParserStructured.node.js`, `OutputParserAutofixing.node.js` | Parse and validate LLM outputs |
| **Memory Systems** | `MemoryBufferWindow.node.js`, `MemoryPostgresChat.node.js`, `MemoryRedisChat.node.js` | Maintain conversation context |

## Configuration and Credentials

AI nodes use n8n's credential system for secure API key management:

| Credential Type | File | Supported Providers |
| --- | --- | --- |
| **OpenAI** | `OpenAiApi.credentials.js` | OpenAI API, Azure OpenAI |
| **Anthropic** | `AnthropicApi.credentials.js` | Claude models |
| **Vector Stores** | `PineconeApi.credentials.js`, `QdrantApi.credentials.js` | Vector database services |
| **Search** | `SerpApi.credentials.js`, `WolframAlphaApi.credentials.js` | External search and computation |

The credential system integrates with n8n's encryption and secure storage mechanisms, ensuring API keys are protected during workflow execution.
