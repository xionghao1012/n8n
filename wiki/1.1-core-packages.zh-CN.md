Monorepo结构
------------------

n8n使用基于pnpm工作区的monorepo，包含多个相互连接的包。核心包提供了工作流执行、节点管理、CLI接口和Web UI的基本功能。

包职责
------------------------

### CLI包(`n8n`)

提供命令行界面和Express服务器的主入口包。它协调所有其他组件并处理进程生命周期管理。

| 组件 | 描述 | 关键代码实体 |
| --- | --- | --- |
| `bin/n8n` | 主可执行二进制文件 | Oclif命令调度器 |
| `dist/commands/` | CLI命令实现 | `start`, `worker`, `webhook`命令 |
| Express服务器 | REST API和UI服务 | `express@5.1.0`, 中间件栈 |
| 工作流运行器 | 执行编排 | `WorkflowRunner`, `ScalingService` |
| 认证 | 用户管理 | `passport`, `jsonwebtoken@9.0.2` |
| 数据库 | 数据持久化 | `@n8n/typeorm@0.3.20-12`, 迁移 |

### 核心包(`n8n-core`)

包含核心执行引擎、节点类型加载和工作流处理逻辑。

| 组件 | 描述 | 关键代码实体 |
| --- | --- | --- |
| 工作流执行 | 核心执行逻辑 | `WorkflowExecute`类 |
| 节点加载 | 动态节点注册 | `NodeTypes`, `LoadNodesAndCredentials` |
| 二进制数据 | 文件处理工具 | `BinaryDataService`, 文件流 |
| 辅助函数 | 节点执行辅助 | `NodeExecuteFunctions`, `this.helpers` |
| SSH隧道 | 安全连接 | `ssh2@1.15.0`, 隧道管理 |
| HTTP请求 | 外部API调用 | `axios@1.8.3`带代理支持 |

### 工作流包(`n8n-workflow`)

提供基础工作流定义、节点接口和表达式评估。

| 组件 | 描述 | 关键代码实体 |
| --- | --- | --- |
| `INode`接口 | 节点类型定义 | `INodeType`, `INodeTypeDescription` |
| `Workflow`类 | 工作流编排 | 图执行、节点解析 |
| 表达式解析器 | `${}`语法评估 | `ExpressionEvaluatorProxy`, JSMath |
| 验证模式 | 基于Zod的验证 | 输入验证、类型检查 |
| 实用函数 | 数据转换 | `jmespath@0.16.0`, 数据映射 |

### 节点基础包(`n8n-nodes-base`)

包含400多个内置集成节点及其凭据定义。

| 组件 | 描述 | 关键代码实体 |
| --- | --- | --- |
| 节点实现 | 服务集成 | `.node.js`文件、操作处理程序 |
| 凭据定义 | 认证配置 | `.credentials.js`文件 |
| 节点元数据 | 注册信息 | `package.json` n8n部分数组 |
| 实用脚本 | 构建辅助 | `copy-nodes-json.js`, 元数据生成 |

构建系统架构
-------------------------

monorepo使用TurboRepo进行跨包的协调构建，包括TypeScript编译和资产处理。每个包都有针对其内容类型的专门构建步骤。

**构建流水线流程**

**按包划分的构建脚本**

| 包 | 构建命令 | 关键步骤 | 输出结构 |
| --- | --- | --- | --- |
| `n8n` | `tsc -p tsconfig.build.json && tsc-alias -p tsconfig.build.json && node scripts/build.mjs` | 编译CLI、解析路径、自定义构建 | `dist/`, `bin/n8n` |
| `n8n-core` | `tsc -p tsconfig.build.json && tsc-alias -p tsconfig.build.json` | 编译核心引擎 | `dist/`, `bin/`实用工具 |
| `n8n-workflow` | `tsc -p tsconfig.build.json` | 编译工作流定义 | `dist/index.js`, 类型声明 |
| `n8n-nodes-base` | `tsup --tsconfig tsconfig.build.json && pnpm copy-nodes-json && tsc-alias -p tsconfig.build.json && pnpm n8n-copy-static-files && pnpm n8n-generate-translations && pnpm n8n-generate-metadata` | 打包节点、复制资产、生成元数据 | `dist/nodes/`, `dist/credentials/` |
| `@n8n/nodes-langchain` | `tsup --tsconfig tsconfig.build.json && pnpm copy-nodes-json && tsc-alias -p tsconfig.build.json && cp utils/tokenizer/*.json dist/utils/tokenizer/ && pnpm n8n-copy-static-files && pnpm n8n-generate-metadata` | 打包AI节点、复制分词器 | `dist/nodes/`, AI特定资产 |

**开发模式命令**

| 包 | 开发命令 | 监视策略 |
| --- | --- | --- |
| `n8n` | `concurrently -k -n "TypeScript,Node" -c "yellow.bold,cyan.bold" "npm run watch" "nodemon"` | TypeScript监视 + nodemon重启 |
| `n8n-core` | `tsc-watch -p tsconfig.build.json --onCompilationComplete "tsc-alias -p tsconfig.build.json"` | TypeScript监视与别名解析 |
| `n8n-nodes-base` | `tsup --watch --tsconfig tsconfig.build.json --onSuccess "pnpm copy-nodes-json && tsc-alias -p tsconfig.build.json && pnpm n8n-generate-metadata"` | 监视与元数据重新生成 |

工作区配置
-----------------------

pnpm工作区配置为包含多个包目录，通过目录式依赖管理实现一致的版本控制。

### 目录依赖

通过目录系统管理的关键共享依赖：

| 类别 | 依赖 | 版本 |
| --- | --- | --- |
| 实用工具 | `lodash`, `axios`, `uuid`, `nanoid` | 固定版本 |
| 验证 | `zod`, `zod-to-json-schema` | `3.24.1`, `3.23.3` |
| AI/ML | `@langchain/core`, `@langchain/openai` | `0.3.48`, `0.5.0` |
| 构建工具 | `tsup`, `tsx`, `rimraf` | 最新兼容版本 |
