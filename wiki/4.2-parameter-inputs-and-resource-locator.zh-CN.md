# 参数输入与资源定位器 | n8n-io/n8n | DeepWiki

本文档详解n8n用户界面中的参数输入系统，重点介绍资源定位器组件(RLC)。参数输入系统提供多种表单控件用于节点配置，资源定位器是支持实时验证和搜索能力的专业输入组件。

关于节点详情视图容器的一般信息，请参考[节点详情视图(NDV)](https://deepwiki.com/n8n-io/n8n/4.1-node-details-view-(ndv))。前端架构相关主题请参见[前端架构与状态管理](https://deepwiki.com/n8n-io/n8n/4.3-frontend-architecture-and-state-management)。

## 参数输入系统概览

参数输入系统提供多种配置组件的动态渲染，包括：
- 基础组件：文本框、下拉框、开关
- 高级组件：资源定位器、表达式编辑器

组件根据节点参数定义动态生成，支持表达式编辑、实时验证等功能。

## 资源定位器架构

资源定位器组件(RLC)是支持动态选择外部服务资源的复杂输入系统，主要特性包括：
- 多选模式切换
- 实时凭证验证
- 服务集成API

**核心功能模块：**
```typescript
interface ResourceLocatorProps {
  mode: 'list' | 'id';
  validation?: ResourceValidationResult;
  onModeChange: (mode: ResourceLocatorMode) => void;
}
```

## 错误处理机制

| 错误类型            | 提示信息                 | 用户操作               |
|---------------------|-------------------------|-----------------------|
| 未设置凭证          | "请添加凭证"           | 打开凭证管理对话框     |
| 无效凭证            | "请检查凭证有效性"      | 更新凭证信息           |
| 需要搜索条件        | 节点特定提示            | 输入必要搜索参数       |
| 网络/API错误        | 服务特定错误信息        | 重试或检查网络连接     |

## 节点系统集成

### 关键集成点
1. **参数依赖**：主资源变更时自动重置依赖字段
2. **凭证联动**：与凭证管理系统深度整合
3. **实时验证**：即时反馈资源可用性状态

### Google Sheets集成示例
```typescript
// 文档ID与工作表名称的依赖关系
const documentIdRlc = useResourceLocator('documentId');
const sheetNameRlc = useDependentResourceLocator(
  'sheetName', 
  () => documentIdRlc.value
);
```
