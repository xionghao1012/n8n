# 节点详情视图(NDV) | n8n-io/n8n | DeepWiki

本文档详细说明n8n工作流编辑器中的节点详情视图架构，该视图作为核心交互界面用于配置和执行节点操作。

## NDV架构组成

### 核心交互组件
- 参数输入面板
- 执行控制栏
- 数据预览选项卡
- 调试信息面板

### 数据流管理
- 输入/输出数据切换
- 数据分页机制
- 表达式编辑器集成

## 功能实现细节

### 参数输入系统
```typescript
// 参数类型定义示例
interface IParameterDefinition {
  name: string;
  type: NodeParameterType;
  required: boolean;
  description: string;
  default?: any;
}
```

### 执行控制流程
1. 用户点击测试按钮
2. 触发`NDV.actions.execute()`
3. 调用工作流执行引擎
4. 实时反馈执行结果
