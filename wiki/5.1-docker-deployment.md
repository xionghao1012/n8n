# Docker Deployment | n8n-io/n8n | DeepWiki

This document covers the Docker deployment architecture for n8n, including the multi-stage build process, image composition, and deployment pipelines. It focuses on the technical implementation details of containerizing the n8n workflow automation platform.

For information about CLI commands and configuration management, see [CLI Commands and Configuration](https://deepwiki.com/n8n-io/n8n/5.2-cli-commands-and-configuration).

## Docker Image Architecture

The n8n Docker deployment uses a multi-stage build process to create optimized production images. The architecture consists of two main components: a base image and the main n8n application image.
