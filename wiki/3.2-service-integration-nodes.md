### FileMaker Token Management Pattern

```
async function getToken(this: ILoadOptionsFunctions | IExecuteFunctions): Promise<any> {
  const credentials = await this.getCredentials('fileMaker');
  const requestOptions: IRequestOptions = {
    uri: `https://${host}/fmi/data/v1/databases/${db}/sessions`,
    method: 'POST',
    auth: { user: login, pass: password },
    body: { fmDataSource: [{ database: host, username: login, password }] }
  };
  
  const response = await this.helpers.request(requestOptions);
  return response.response.token;
}
```

### FileMaker Token Management Pattern

```
let token;
try {
  token = await getToken.call(this);
} catch (error) {
  throw new NodeOperationError(this.getNode(), error as string);
}

// Execute operations with token
// ...

// Always logout to clean up session
await logout.call(this, token as string);
```

### Yourls Simple Pattern

```
if (resource === 'url') {
  if (operation === 'shorten') {
    qs.url = url;
    qs.action = 'shorturl';
  } else if (operation === 'expand') {
    qs.shorturl = shortUrl;
    qs.action = 'expand';
  } else if (operation === 'stats') {
    qs.shorturl = shortUrl;
    qs.action = 'url-stats';
  }
}
```

### Service Integration Comparison

| Feature | NextCloud | FileMaker | Yourls |
| --- | --- | --- | --- |
| Authentication | Access Token + OAuth2 | Username/Password | API Signature |
| Binary Data | Advanced file handling | Not applicable | Not applicable |
| Dynamic Options | Not implemented | Comprehensive schema loading | Not applicable |
| Session Management | Stateless | Token-based sessions | Stateless |
| Error Handling | HTML error detection | JSON validation | API status checking |

## Building New Service Integrations

### Implementation Checklist

| Component | Required Files | Key Considerations |
| --- | --- | --- |
| **Action Node** | `ServiceName.node.ts` | Implement `INodeType`, define resources/operations |
| **API Helpers** | `GenericFunctions.ts` | Request function, authentication, error handling |
| **Credentials** | `ServiceNameApi.credentials.ts` | Authentication implementation |
| **Testing** | `ServiceName.node.test.ts` | Unit tests for core functionality |
